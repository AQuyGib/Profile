HƯỚNG DẪN TÍCH HỢP

Hệ thống hỗ trợ 2 dạng sử dụng chính vào dự án **Profile 3D Nguyễn Anh Quý** của bạn:

Cách 1: Vẽ Trực Tiếp Bằng Code (Khuyên dùng)

Không tốn băng thông tải ảnh, tăng hiệu suất tuyệt đối. Bạn dán hàm code vẽ nhận được vào vòng lặp cập nhật màn hình Canvas (`requestAnimationFrame`) trong tệp `game-2d.js` hoặc bất kỳ đâu.

Cách 2: Sử Dụng Ảnh Tĩnh PNG

Bấm vào biểu tượng để lưu file ảnh dạng PNG trong suốt chất lượng cao, sau đó nạp bình thường qua `new Image()` trong Javascript.

Trình trạng: Toàn bộ mã nguồn hoàn toàn độc lập, sử dụng API vẽ vector tiêu chuẩn của trình duyệt.
